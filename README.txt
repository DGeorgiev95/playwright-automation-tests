# PlayLab — Playwright Automation Tests

A portfolio project demonstrating UI test automation using Playwright, TypeScript, and Node.js

## Test Coverage

- Authentication and form validation
- Interactive UI elements and file uploads
- Data table sorting, filtering, and pagination
- Editable tables and calculated totals

## Tech Stack

- Playwright Test
- TypeScript
- Node.js / npm

## Setup

```bash
git clone https://github.com/DGeorgiev95/playwright-automation-tests.git
cd playwright-automation-tests
npm ci
npx playwright install
```

## Run Tests

```bash
npx playwright test
```
